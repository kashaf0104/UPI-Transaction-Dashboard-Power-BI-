# UPI-Transaction-Dashboard-Power-BI-

💳 UPI Transaction Analytics Dashboard (Power BI)
This project showcases an interactive UPI Transaction Analytics Dashboard built using Power BI, designed to analyze digital payment trends, user behavior, and transaction patterns across different cities, banks, and payment methods.


🔧 Tools & Technologies Used
Power BI
Power Query (Data Cleaning & Transformation)
Microsoft Excel (Data Source)


📁 Dataset Description
The dataset includes UPI transaction details such as:
Transaction Date
Bank (Sender & Receiver)
City
Payment Method (UPI ID, Phone Number, QR Code)
Merchant Name
Device Type (Mobile, Tablet, Laptop)
Transaction Type (Payment/Transfer)
Gender & Age Group
Transaction Amount & Remaining Balance
Status (Success/Failed)


⚙️ Data Preparation
Cleaned raw data using Power Query
Removed inconsistencies and handled missing values
Created calculated measures (Total Amount, Balance, Transaction Count)
Structured data for time-based and categorical analysis


📊 Dashboard Features
Interactive slicers for:
Bank (Sent & Received)
City
Gender
Age Group
Device Type
Payment Method
Transaction Type
Date Range


📌 Key KPIs
Total Transactions: 20,000
Total Transaction Amount: 19.87M
Remaining Balance insights included


📈 Key Insights
Monthly Trends: Transactions remain consistent across months (~1.6M–1.7M)
City-wise Analysis: Major contributions from Bangalore, Delhi, Hyderabad, and Mumbai
Payment Methods: UPI ID, Phone Number, and QR Code are almost equally used
Transaction Status: Majority transactions are successful (~80%)
Device Usage: Mobile devices dominate UPI transactions
Top Merchants: Zomato, Swiggy, Amazon, Flipkart, IRCTC show high transaction volume
Spending Purpose: Travel, Shopping, Food, and Bill Payments are major categories
Gender Analysis: Transactions are distributed across male and female users


🎯 Project Objective
To:
Analyze digital payment behavior
Identify transaction trends and user preferences
Provide insights for financial decision-making and business strategies
🚀 Key Features
Fully interactive dashboard with dynamic filtering
Combination of charts: Line, Column, Donut, Treemap, and Waterfall
Easy-to-understand visual storytelling
Real-time analysis capability
🔗 Conclusion
This dashboard helps understand how users interact with UPI platforms, enabling better insights into customer behavior, transaction patterns, and digital payment growth.
